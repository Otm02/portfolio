# Maintaining athmanebenarous.com

## Everyday edits

All content is in `src/content/`. Edit a file, open a PR, check the preview link Cloudflare posts on it, merge. Production deploys about a minute after the merge.

| To change | Edit |
| --- | --- |
| Hero, status line, education, skills | `src/content/profile/profile.yaml` (bump `lastUpdated`) |
| A job | `src/content/experience/<slug>.md` |
| A case study | `src/content/work/<slug>.md` (`order` sets card position; `featured: false` hides it from the home page) |
| A paper | `src/content/papers/<slug>.md` + the PDF in `public/papers/<slug>.pdf` |
| A project | `src/content/projects/<slug>.md` (`archive: true` puts it under "Earlier hackathons") |
| CVs | replace `public/cv.pdf` and `public/cv-fr.pdf` (keep the names) |

Dates are `YYYY-MM`. A missing field or a bad date fails the build with a message naming the file, so a typo never ships.

Before pushing, run locally (Node 22.12+):

```sh
npm install
npm run check   # types and content schema
npm run build   # must end with "Complete!"
npm run dev     # http://localhost:4321
```

### Content rules worth keeping

- Never call a paper "published", "accepted" or "under review", and never name a venue.
- No co-author names, GPA or phone number on the site.
- Slow-leak work: keep "the gain is conditional" and "not certified for operational use".
- Russet House and Chemia: describe in general terms only (Chemia is under NDA).

## Diagrams

Case-study diagrams are written as `<!-- diagram: name | caption -->` in Markdown and defined in `src/lib/diagrams.mjs`. After editing `diagrams.mjs`, clear Astro's content cache or the old diagram is reused:

```sh
rm -rf .astro node_modules/.astro && npm run build
```

## Hosting

- **Cloudflare Workers (static assets)**, Worker `athmanebenarous`, built by Workers Builds from `main`. Config: `wrangler.jsonc`.
- **Previews:** every branch build gets `<branch>-athmanebenarous.atho5850.workers.dev` and `<branch>.athmanebenarous.com`. Previews need the `"previews": {}` block in `wrangler.jsonc`; don't remove it.
- **Domain:** `athmanebenarous.com` is a Worker **Custom domain** (not a Route). `www` is a proxied `AAAA 100::` record with a "Redirect from WWW to root" rule. Nameservers are Cloudflare's, set at Spaceship.
- **Headers and redirects:** `public/_headers` and `public/_redirects`.
- **Analytics:** Cloudflare Web Analytics; the token is in `src/layouts/Base.astro`.
- **CSP:** generated by Astro (`security.csp` in `astro.config.mjs`). A new external script or style needs adding there.

## Rollback

- **Bad deploy:** Cloudflare → Worker → Deployments → pick the previous version → Rollback. Or revert the PR on GitHub.
- **Cloudflare itself:** the old site still lives on the `legacy` branch. Until GitHub Pages is retired (below), you can remove the Worker custom domain and add `A @` → `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153` (DNS only).

## Retiring GitHub Pages

Once the site has been stable for a couple of weeks: GitHub → `Otm02/portfolio` → Settings → Pages → remove the custom domain and unpublish. After that, rollback is by Cloudflare deployments only.

## Dependencies

`npm outdated`, then update in a branch and let the preview build prove it. `npm audit` reports two moderate issues in `fflate` via `satori`; satori only renders OG images at build time, so nothing reaches visitors.
